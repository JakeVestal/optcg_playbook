Import TCGplayer orders

  1. One-time setup: the OPTCG import bookmark is installed by hand from Jacob's computer (python3 tools/build_bookmarklet.py). For safety it isn't available on this website.
  2. Open your TCGplayer Order History (logged in) and click the bookmark. It reads every page by itself and opens this site with your orders.
  3. Check the preview and click Add. Orders already imported are skipped, so run it whenever you've bought something.

Safety: never install an "import" bookmark from a website or a link someone sends you. The real one only reads your order-history pages: it loads no code from anywhere and can't place orders or change anything on TCGplayer.

Privacy: the bookmark reads only order dates, shipping status, estimated delivery dates, and each item's product, quantity and price paid. Names, addresses, payment details and sellers are never read, and order numbers are stored only as a one-way code. Imported purchases are saved in the shared collection file in the public GitHub repo.
